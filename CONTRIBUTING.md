# Contributing to Sword and Sorcery

Thank you for your interest in contributing to Sword and Sorcery! This document provides guidelines and instructions for contributing to this project.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and constructive in your interactions.

## How to Contribute

1. **Fork the Repository**: Create your own fork of the repository.

2. **Create a Branch**: Create a branch for your contribution.
   ```
   git checkout -b feature/your-feature-name
   ```

3. **Make Changes**: Make your changes to the codebase.

4. **Write Tests**: If applicable, write tests for your changes.

5. **Run Tests**: Ensure all tests pass before submitting.
   ```
   npm test
   ```

6. **Commit Changes**: Use clear, descriptive commit messages.
   ```
   git commit -m "Add feature: description of the changes"
   ```

7. **Push Changes**: Push your changes to your fork.
   ```
   git push origin feature/your-feature-name
   ```

8. **Submit a Pull Request**: Create a pull request from your branch to the main repository.

## Development Setup

Follow the instructions in the README.md file to set up the development environment.

## Code Style

- Follow the existing code style in the repository.
- Use TypeScript for new frontend components.
- Use ESLint and Prettier for code formatting.

## Testing

- Write unit tests for new functionality.
- Ensure all tests pass before submitting a pull request.

## Documentation

- Update documentation for new features or changes to existing functionality.
- Include comments in your code where necessary.

## Issue Reporting

If you find a bug or have a feature request, please create an issue on the repository with a clear description of the problem or request.

## Review Process

All pull requests will be reviewed by project maintainers. You may be asked to make changes before your pull request is accepted.
